How to write a bot (API)

Each control tick (~120 Hz) your code runs with these variables in scope. Set motor power with setMotors(left,right), each -1…1. The first 5 s are a forced freeze (motors ignored) — sensors are live, so plan into memory.

  • enemy — {detected, distance /*cm*/, bearing /*deg, +right/−left, 0=ahead*/}
  • sensors — array of IR rays [{angle, distance}] (distance=Infinity if nothing)
  • edge — line sensors at corners {fl, fr, bl, br} = true when over the white border
  • time — seconds since the freeze ended (negative during countdown)
  • frozen — true during the 5 s countdown
  • memory — a {} that persists across ticks (your robot's RAM)
  • start — your chosen start position 1–4 (Figure 2), in case your code wants to branch on it
  • log(...) — print to the console panel

Win a round by pushing the opponent's center past the ring edge, or if it stalls (stops >5 s). Best of 3. This mirrors real firmware: sense → decide → drive. JS here, but the logic ports straight to Arduino/C.
